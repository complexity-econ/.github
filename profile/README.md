# Computational complexity economics

**Computational complexity economics** — agent-based models, stock-flow consistent accounting, and Monte Carlo simulation for macroeconomic policy analysis.

## Research focus

- **Non-ergodic dynamics** in fiscal and monetary policy
- **Phase transitions & bifurcations** in agent-based macro models
- **Stock-Flow Consistent (SFC)** balance-sheet accounting
- **Watts-Strogatz networks** for firm–household interaction topology
- **Monte Carlo robustness** testing across parameter space
